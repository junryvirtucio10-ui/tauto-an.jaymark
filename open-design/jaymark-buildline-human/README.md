# Jaymark Buildline — human revision

This package replaces the static, generated portfolio treatment with a light editorial working canvas, mixed-case type, service indexes, spacious project case notes, and one meaningful interaction: a live responsive project frame.

Use `OPEN-DESIGN-REFINE.md` to update the existing Open Design system. Use `DESIGN.md`, `tokens.css`, and `components.html` as supporting source material.

Upload all three files from `fonts/` with Open Design's **Add brand font files** action before judging the typography preview:

- `Archivo-Variable.ttf`
- `AtkinsonHyperlegibleNext-Variable.ttf`
- `IBMPlexMono-Medium.ttf`

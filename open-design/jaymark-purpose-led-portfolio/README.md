# Jaymark Purpose-Led Portfolio

A portable Open Design system extracted from Jaymark Tauto-an's portfolio implementation. It pairs deep ink and navy editorial sections with winter-blue surfaces, Bricolage Grotesque display type, DM Sans body copy, IBM Plex Mono utility labels, and direct blue conversion actions.

Use `DESIGN.md` for design intent and component rules. Use `tokens.css` as the canonical implementation contract.

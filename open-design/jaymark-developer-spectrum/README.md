# Developer Spectrum

A standalone developer-portfolio design system and direct-build reference, created from the supplied palette:

`#E66000` · `#FF9500` · `#FFCB00` · `#00539F` · `#0095DD` · `#331E54` · `#002147`

Open Design is not required. Use `components.html` as the visual prototype, `tokens.css` as the implementation source, and `DESIGN.md` as the written rules while building the production portfolio directly.

The component preview uses Sora for headings, Instrument Sans for body and interface copy, and IBM Plex Mono for technical information. Gradients are deliberately role-based: warm for actions and interface emphasis, cool for systems and depth, with one slow spectrum movement in the hero.

Interactive patterns include the Discover/Build/Test/Ship pipeline, responsive desktop/tablet/mobile project views, and accessible capability disclosures. All controls are keyboard-operable and the transition layer respects reduced-motion preferences.
